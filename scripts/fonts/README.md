# Fuentes para medir texto

`CantoralMetrics-*.ttf` son un **recorte de Carlito** (solo caracteres latinos y
signos, ~35 KB cada una) que usa `scripts/villancicos_docx.py` para medir en
píxeles el texto del Word de los Villancicos Solidarios: Carlito tiene las
**mismas medidas** que Calibri (la fuente del Word), y en sus cuatro estilos,
porque una línea de acordes en negrita no mide lo mismo que en normal.

No se usan para pintar nada, solo para medir. Se han renombrado porque la
licencia (SIL Open Font License 1.1, texto completo en `OFL.txt`) reserva el
nombre «Carlito» para la fuente original y un recorte es una versión
modificada.
