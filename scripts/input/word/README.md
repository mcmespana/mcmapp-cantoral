# Words sueltos con canciones del cantoral

Los `.docx` que se dejen aquí salen en el **Cantoral Admin → 📥 Importar del
cantoral**, junto a las del Word grande del cantoral (etiqueta 📄 con el nombre
del Word). Son canciones del **cantoral normal**: al importarlas se elige la
categoría en la columna «Sección» y quedan como un `.cho` más en `songs/`.
Detalles en `scripts/admin/README.md` («Words sueltos»).
